# Flower Shop バックエンドシステム

これは花屋オンラインでセールス向けのバックエンドシステムです。

本システムには、管理者ページとユーザーページの両方が含まれています。

ユーザーのロールが管理者に設定されていない場合、管理者ページへアクセスすることはできません。

管理者ページには、以下の4つの主要機能があります。

- 商品管理
- カテゴリ管理
- 注文管理
- お知らせ管理

保護されたAPIへのアクセス制御には、セッション認証およびトークンベース認証を使用しています。

有効な認証トークンを持たないユーザーは、制限されたAPIを利用できません。

注文作成時には、重複注文および在庫超過販売を防ぐために楽観ロックを実装しています。

さらに、rabbitMQを用いて、一定時間内で未払いなら、自動でオーダーを削除して、在庫を戻させます。

## インストール手順

1. このリポジトリをローカル環境へクローンしてください。

2. `flowershoppingDB` という名前のMySQLデータベースを作成してください。

3. アプリケーション起動前に、作成したデータベースに対して `db-src` フォルダ内のすべてのSQLスクリプトを実行してください。

4. `application.properties` の環境設定を行ってください。
   ローカル環境に応じて設定値を変更できます。
